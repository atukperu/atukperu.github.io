# ATUK · Polos básicos

Web de ATUK: polos básicos de hombre, 100% algodón, cuello redondo. Colores negro, azul, crema y verde militar.

- Armador de packs (x1, x2, x3, x4) con talla por polo y pedido directo por WhatsApp.
- Envío gratis a Lima Metropolitana desde el pack x2. Provincias vía Shalom.

## Editar precios o número
En `index.html`, busca el bloque `EDITA AQUÍ` dentro del `<script>`: número de WhatsApp, precio unitario, packs y desde cuántos polos el envío es gratis.

## Estructura
- `index.html`: la página completa
- `img/`: fotos de producto
- `logo/`: logo ATUK en vector (SVG)
- `mirada.mp4`, `mirada-movil.mp4`, `lobo.mp4`: videos de la portada y la banda del lobo
